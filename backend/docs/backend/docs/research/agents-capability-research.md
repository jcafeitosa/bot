

## Complemento: documentação de desenvolvimento Meta

A documentação oficial preservada em [Meta Model API — overview](../external-sources/meta-model-api-overview.md) descreve Muse Spark servido pela Meta Model API, com chamadas paralelas a ferramentas, argumentos de tool calls transmitidos em streaming, contexto de 1.048.576 tokens e Responses API com raciocínio contínuo entre turnos e estado gerido pelo servidor. Também descreve Muse Code como agente de programação que planeja, edita arquivos e executa comandos, com aprovações e sandbox ativos por padrão.

**Implicação para o módulo:** essas são capacidades de inferência e execução para avaliação numa fase futura de cérebro/runtime. Não pertencem ao registro de identidade `IdentityOnly` e não justificam adotar Meta como fornecedor. A captura preserva a fonte primária; as outras fontes externas listadas acima ainda precisam de captura local para satisfazer o ciclo de evidência desta base.
